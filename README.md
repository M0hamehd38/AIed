# کلاس‌یار — دستیار هوشمند آموزش

پلتفرمی برای استاد دانشگاه: دیدن تسلط دانشجویان روی مفاهیم درس از روی آزمونک‌های زنده، با پیشنهادهای آموزشی مبتنی بر شواهد که فقط با تأیید استاد اجرا می‌شوند.

## صفحه‌ها

- `index.html` — صفحه‌ی ابتدایی سایت. با اسکرول (یا کلیدهای جهت، یا نقطه‌های کنار صفحه) دوربین از کنار بات وارد کلاس می‌شود، ویژگی‌ها یکی‌یکی دیده می‌شوند و در پایان به تخته می‌رسد. روی گوشی چیدمان عمودی جداگانه دارد.
- `panel.html` — پنل استاد (پروتوتایپ تعاملی با داده‌ی شبیه‌سازی‌شده). فقط بعد از «ورود» یا «ثبت‌نام» در صفحه‌ی ابتدایی باز می‌شود؛ دکمه‌ی خروج در نوار بالا است.
- `assets/` — تصویرهای صفحه‌ی ابتدایی (کلاس، بات، تیتر، آرم).
- `fonts/` — فونت ساحل (مجوز SIL OFL).
- `docs/` — شرح نیازمندی‌ها و برنامه‌ی فاز ۰.

## اجرا

فایل‌ها ایستا هستند. چون صفحه‌ها تصویر و فونت را از پوشه‌های کناری می‌خوانند، از یک وب‌سرور ساده استفاده کنید:

```
python3 -m http.server 8000
```

و سپس `http://localhost:8000` را باز کنید.

> ورود و ثبت‌نام در این نسخه نمایشی است: اطلاعات فقط در مرورگر همان کاربر ذخیره می‌شود و سروری در کار نیست. احراز هویت واقعی در فاز ۱ (Django) اضافه می‌شود.

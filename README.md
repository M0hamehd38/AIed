# کلاس‌یار — دستیار هوشمند آموزش

پلتفرمی برای استاد دانشگاه: دیدن تسلط دانشجویان روی مفاهیم درس از روی آزمونک‌های زنده، با پیشنهادهای آموزشی مبتنی بر شواهد که فقط با تأیید استاد اجرا می‌شوند.

## وضعیت

- `prototype.html` — پروتوتایپ تعاملی پنل استاد (کافی است در مرورگر باز شود). فونت: ساحل (Sahel، مجوز SIL OFL) در پوشه‌ی `fonts/`؛ فایل HTML باید کنار این پوشه باشد. داده‌ها شبیه‌سازی‌شده‌اند و با بارگذاری دوباره بازنشانی می‌شوند.
- `docs/CLASSYAR_PROMPT.md` — شرح کامل نیازمندی‌ها و فازبندی
- `docs/PHASE0_PLAN.md` — برنامه‌ی فاز ۰ (نسخه‌ی پایتون، Django) — منتظر تأیید

## گام بعد

فاز ۱: اسکلت پروژه با Django، سیستم طراحی، صفحات پنل استاد با داده‌ی نمونه، احراز هویت و نقش‌ها، Docker Compose.

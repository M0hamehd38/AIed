# فونت‌ها

پروتوتایپ ابتدا فونت **انجمن** (Anjoman) و در صورت نبود آن **ایران‌سنس** (IRANSans) را استفاده می‌کند.
هر دو فونت تجاری هستند و فایلشان در این ریپو قرار نگرفته است.

پس از تهیه‌ی نسخه‌ی دارای مجوز، فایل‌ها را با این نام‌ها در همین پوشه بگذارید:

```
fonts/Anjoman-Regular.woff2    fonts/Anjoman-Bold.woff2
fonts/IRANSans-Regular.woff2   fonts/IRANSans-Bold.woff2
```

(فرمت `woff` هم با همین نام‌ها پشتیبانی می‌شود.) اگر فونت روی سیستم نصب باشد، بدون فایل هم کار می‌کند.
در غیر این صورت صفحه با Vazirmatn یا Tahoma نمایش داده می‌شود.

> اگر ریپو عمومی است، فایل فونت‌های تجاری را commit نکنید.
